Database & performance

The backend uses relational data and JPA/Hibernate. Areas covered in the engineering work include indexes, repository query design, connection pooling, pagination and avoiding unnecessary database access.

Indexes

Indexes support frequently filtered, joined or sorted data.

HikariCP

Connection pooling controls how application threads reuse database connections.

Queries

Repository design and query analysis help reduce unnecessary database work.

Project detail

Large file workflow

Large File→Chunk 1..N→Backend→Temporary Storage→Merge→Final File

The upload work includes chunk handling, merging and cleanup of temporary data. This is a strong example of solving practical large-file and network constraints instead of relying only on a single multipart request.

Project detail

Concurrent appointment booking

A key consistency problem in booking systems is two users attempting to claim the same slot at nearly the same time. Transactional/concurrency controls are used so the database remains the source of truth and the business invariant is protected.

User A ──→ Booking Request ──┐
                             ├──→ Transaction / DB consistency
User B ──→ Booking Request ──┘

Messaging & distributed communication
