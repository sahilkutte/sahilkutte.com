Large file workflow

Chunk upload → merge → final file

Large File→Chunk 1..N→Backend→Temporary Storage→Merge→Final File

The upload work includes chunk handling, merging and cleanup of temporary data. This addresses practical large-file and network constraints rather than depending only on one very large multipart request.

Concurrency

Appointment booking consistency

A key consistency problem in booking systems is two users attempting to claim the same slot at nearly the same time. Transactional/concurrency controls protect the business invariant and keep the database as the source of truth.

User A ──→ Booking Request ──┐
                             ├──→ Transaction / DB consistency
User B ──→ Booking Request ──┘
Communication

Messaging & distributed communication

Kafka and RabbitMQ are part of the broader engineering toolkit used across the work. Messaging is useful when work can be decoupled from the initiating HTTP request, allowing consumers to process events asynchronously.
